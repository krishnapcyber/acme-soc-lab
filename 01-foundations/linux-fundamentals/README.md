# Linux Fundamentals for Security Operations

## Objective

Establish the baseline Linux command-line skills required to operate
a cybersecurity workstation, as a foundation for later SOC, network
security, and detection engineering projects in this lab.

## Commands Practiced

### whoami

Displays the current user

### pwd

Displays the current working directory

### ls

Lists files and directories

### cd

Changes the current directory.

### mkdir

Creates a directory.

### sudo

Executes an authorized command with elevated privileges.

### ip addr

Displays network interfaces and IP configuration.

### ip route

Displays the routing table

### ping

Tests network connectivity.

## Cybersecurity Relevance

Linux is widely used in cybersecurity operations,
security engineering, penetration testing, servers, 
cloud infrastructure and security tooling.

Understanding linux fundamentals is therefore essential
for working effectively in cybersecurity.

## Lessons Learned

1. Linux uses directories to organize files
2. Users have different privileges.
3. root is a highly privileged account.
4. Network interfaces have IP addresses.
5. Routing determines where network traffic is sent.
6. ping can be used to test connectivity.
