# ACME SOC Lab

Hands-on cybersecurity home lab covering SOC fundamentals, network
security, and (expanding into) cloud security and detection
engineering. Each project folder documents the objective, what was
built, and its relevance to real SOC/security operations work.

## Projects

| Project | Skills Demonstrated |
|---|---|
| [Linux Fundamentals](./01-foundations/linux-fundamentals) | Core Linux CLI, user/privilege model, basic network commands |
| [Networking Fundamentals](./01-foundations/networking) | IP addressing, routing, DNS, TCP/UDP, ports, HTTP/HTTPS, troubleshooting methodology |

| [Network Reconnaissance & Nmap](./02-network-recon-nmap) | Active scanning, service enumeration, CVE identification, attack surface analysis |

More projects (network reconnaissance/Nmap, SIEM log analysis, cloud
security, detection engineering) are in progress and will be added
as separate project folders.

## Note on Lab Data

All IPs, hostnames, and MAC addresses shown in this lab are from an
isolated local environment and are redacted or fictional where
sensitive. All testing is performed only against systems I own or
am authorized to test.
